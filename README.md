# Day of My Life

See which day of your life you are on. Your birthday is day one. Includes a day/date lookup, "When I was your age", and a King James verse for the day.

- Live app: https://quickinfinity.github.io/day-of-my-life/
- Embedded at: https://ibrainos.com/day-of-my-life/ (WordPress page 53, iframe)

Single static file (`index.html`), no build step. Push to `main` and GitHub Pages updates the site. The birthdate and other entries stay in the visitor's browser (localStorage).
